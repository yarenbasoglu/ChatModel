# Deney raporları

`baseline_metrics.json` yalnızca gerçek eğitim çalıştırıldığında üretilir.
Macro-F1, sınıf başına precision/recall/F1, confusion matrix, validation eşiği,
veri SHA-256 değerleri, örnek sayıları, donanım, model dosya boyutu ve 300
tek-mesaj CPU gecikme ölçümünün özeti bulunur.

Testler içindeki küçük yapay örnekler yalnızca yazılım davranışını doğrular;
ürün modeli veya akademik performans raporu üretmek için kullanılmaz.
